# The kit's icons

The client's own, 64px, lifted from the wardrobe build
(`public/lab/doll/items/icons/`, which is gitignored — 12,459 files — while
these eight are tracked, the way `public/pins/map-x.png` is).

docs/TARI.md §7.1 keeps real icons for content and drawn vectors for the UI
vocabulary. These are content: every one of them is a thing you can go and buy
in the game, which is the whole point of the card it sits on.

**The two argument cards wear the closest real objects the game has** (Kacey,
2026-08-30). Neither is a thing you can buy, so each is a metaphor rather than
an instruction — but both are still the client's own art, which is the half of
§7.1 that matters here: nothing in this folder was drawn by us.

| `inv_misc_enggizmos_10` | The addon only listens | an engineering part — a device you bolt on that reports and does nothing else |

one of these, because what it is asking for is a pin.
